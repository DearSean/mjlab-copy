# LaFAN1 recovery-review subset

This directory contains the 17 unchanged LaFAN1 BVH files referenced by
`artifacts/recovery/review/review_queue.json`. Together they are sufficient to
resume all segment, validation, and test review modes in this repository. They
are a subset of the original 77-file dataset, not a modified or retargeted
dataset.

Source: [Ubisoft La Forge Animation Dataset (LaFAN1)](https://github.com/ubisoft/ubisoft-laforge-animation-dataset)

LaFAN1 was introduced with *Robust Motion In-betweening* by Félix G. Harvey,
Mike Yurick, Derek Nowrouzezahrai, and Christopher Pal (SIGGRAPH 2020). The data
is distributed by Ubisoft under CC BY-NC-ND 4.0. See `LICENSE.txt` in this
directory. The dataset license is separate from mjlab's Apache-2.0 code license.

The files are included only to make the non-commercial academic review workflow
portable. Do not use or redistribute them for commercial purposes, and do not
publish modified versions under the LaFAN1 license.
